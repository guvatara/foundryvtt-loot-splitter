# Loot Splitter — Делёж добычи

Модуль для [Foundry VTT](https://foundryvtt.com): GM перетаскивает в окно модуля предметы и указывает золото, а модуль распределяет добычу между персонажами игроков — поровну или по ручному назначению — и пишет итог в чат.

A [Foundry VTT](https://foundryvtt.com) module: the GM drags items into the module window, enters a gold amount, and the module splits the loot between player characters — evenly or by manual assignment — logging the result to chat.

## Возможности / Features

- Окно делёжи открывается кнопкой (монетки) в панели инструментов сцены (только для GM) или чат-командой `/loot`.
- Drag & Drop предметов из боковой панели, компендиумов и листов персонажей.
- Поле золота и **доли у получателей** (1, 0.5, 2…): золото делится пропорционально долям, остаток — по наибольшей дробной части. Доля 0 = участник ничего не получает (удобно для «полпайки» NPC-гиду).
- Два режима:
  - **Поровну** — золото пропорционально долям, предметы раздаются взвешенным round-robin (большая доля — чаще очередь).
  - **Ручное назначение** — у каждого предмета свой получатель, золото делится по долям.
- Реальное начисление: предметы создаются на листах персонажей, золото добавляется в `system.currency` (для dnd5e по умолчанию `gp`, номинал настраивается).
- Лог распределения в чат: публичное сообщение или шёпот GM (настройка мира).
- История дележей: каждая раздача добавляется страницей с датой и временем в журнал мира «Делёж добычи — история» (отключается в настройках).
- Локализация: русский и английский.

## Установка / Installation

В Foundry VTT: *Add-on Modules → Install Module → Manifest URL*:

```
https://github.com/guvatara/foundryvtt-loot-splitter/releases/latest/download/module.json
```

Обновления приходят автоматически при выходе нового релиза. Альтернатива для разработки — манифест из ветки `main`: `https://raw.githubusercontent.com/guvatara/foundryvtt-loot-splitter/main/module.json`.

**Как выпустить новую версию:** поставьте тег и запушьте его — GitHub Actions соберёт `module.zip`, проставит версию и `download` в `module.json` и опубликует релиз:

```bash
git tag v0.2.0 && git push --tags
```

## Использование / Usage

1. Нажмите кнопку «Делёж добычи» (иконка монет) в разделе инструментов токена на панели управления сценой.
2. Перетащите предметы в область окна и укажите сумму золота.
3. Отметьте получателей (персонажи игроков подтягиваются автоматически).
4. Выберите режим «Поровну» или «Ручное назначение».
5. Нажмите **Распределить** — предметы и золото попадут на листы персонажей, а в чат уйдёт сводка.

## Совместимость / Compatibility

- Foundry VTT: v12–v14 (ApplicationV2 + HandlebarsApplicationMixin).
- Системы: любые с dnd5e-подобной структурой `system.currency`; для прочих систем предметы раздаются, а по золоту выводится предупреждение.
